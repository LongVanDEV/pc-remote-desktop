# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.2.x   | ✅ |
| < 0.2   | ❌ |

## Reporting a vulnerability

Email security reports to the maintainers via GitHub Security Advisories on this repository.

Please include:

1. Impact assessment
2. Reproduction steps
3. Affected component (host / viewer / signaling)

Do **not** open public issues for active exploits.
